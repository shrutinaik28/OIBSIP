# 📄 Nmap Scan Report - Task 1

## 🎯 Objective

Perform a network scan using Nmap to identify open ports, running services, and basic network information of an authorized target machine.

---

## 🛠️ Tools Used

- **Tool:** Nmap 7.95
- **Platform:** Kali Linux

---

## 🔍 Nmap Commands Used

```bash
nmap 192.168.130.128
nmap -sV 192.168.130.128

```
## 📊 Scan Results

The scan identified the open ports and running services on the target machine.
